# 永豐餘消費品｜AI 文案 x 生圖 側邊欄（橘子工坊／五月花／得意／蒲公英）

Google Sheets 的 Apps Script 側邊欄，掛在 CPAS 廣告素材入稿表上用。
不會改動試算表任何內容，所有產出只顯示在側邊欄，要不要用由人決定。

貼近實際流程：**先在網路上找到「想要這種感覺」的圖、或丟自己的舊稿 → 拖進側邊欄 → 用中文講要什麼 → 模型依 momo 稿的固定版型規範，把正確品牌、日期、價格、文字直接畫進 1:1 成品 → 繼續打字修改 → 一鍵產出給設計師的需求單**。
所有操作都在側邊欄內完成，圖片直接拖放、選檔、Ctrl+V 貼上或貼網址，不需要先整理雲端硬碟。

側邊欄只有兩個區塊：

| 區塊 | 做什麼 |
|---|---|
| 文案 | 填商品、選調性，有時事就先「提 5 個切角」，再「生成 3 版文案」，點一版當選定 |
| 圖 | 一個拖放區丟圖，每張可點標籤切換成 參考／原稿／版型／產品／logo（有透明邊的自動當產品）；一個對話框用中文講要什麼，沒靈感按「依文案產生風格提示 →」；選排法、強調色、品質、比例，按「產圖」；繼續打字就是改上一張。成品直接顯示在下方，「只畫背景」模式可疊上真實產品圖並拖曳；「下載」「存雲端」「需求單」都在同一處 |

生圖走 OpenAI Responses API 的 `image_generation` 工具，也就是 ChatGPT 生圖背後同一套機制：GPT 先看懂中文、參考圖、產品圖，自己寫指令產圖，之後用 `previous_response_id` 延續修改；影像模型不指定版本，交給 OpenAI 用最新的（目前是 gpt-image-2）。

## 安裝

1. 開入稿表 → **擴充功能 → Apps Script**。
2. 把 `Code.gs` 全部內容貼進編輯器的 `Code.gs`（取代原本內容）。
3. 左側「檔案」旁按 ＋ → HTML，命名 `Sidebar`（不要打副檔名），貼上 `Sidebar.html` 全部內容。
4. Ctrl+S 存檔，回試算表 **重新整理整個分頁**，選單列會出現「AI 文案工具」。
5. 「AI 文案工具 → 設定 OpenAI API Key」貼上金鑰。第一次會要求授權：選帳號 → 進階 → 前往專案 → 允許。
6. 「AI 文案工具 → 開啟 AI 文案側邊欄」，開始用。

## 之後更新：一鍵從 GitHub 更新，不用再貼程式碼

一次性設定（每個會按「更新」的人各做一次，其他人只用側邊欄不用做）：

1. 用同一個 Google 帳號到 https://script.google.com/home/usersettings ，把「Google Apps Script API」打開。
2. Apps Script 編輯器 → 左側齒輪「專案設定」→ 勾「在編輯器中顯示 appsscript.json 資訊清單檔案」。
3. 左側會多出 `appsscript.json`，把 repo 裡的 `appsscript.json` 全部貼進去取代，Ctrl+S。
4. 回試算表重新整理，「AI 文案工具 → 更新程式到最新版（從 GitHub）」。第一次會再要求授權一次（多了「修改 Apps Script 專案」權限，這是讓它能寫回自己）。

之後每次有新版本，按同一個選單就好。它會比對 GitHub 上的 `Code.gs`、`Sidebar.html`、`appsscript.json`，有差才寫回，寫完提醒重新整理。API Key 存在指令碼屬性，不會被更新動到。
更新來源寫在 `Code.gs` 的 `UPDATE_SOURCE`（目前指向 `claude/enable-apps-script-42hub0` 分支）；日後合併到 `main` 就把 `branch` 改成 `main`。repo 若改成私有，在「專案設定 → 指令碼屬性」加 `GITHUB_TOKEN`（fine-grained token，只要 Contents: Read）。

選用項目，不做也能用：

- 「建立產品資料分頁」：新增「產品資料」分頁並填入範本，A 欄關鍵字只要包含在「品類」文字裡就自動帶入賣點。
- 「建立雲端硬碟常用素材庫」：在雲端硬碟建四個資料夾，放每次都會用到的產品去背圖、設計師成品與 logo。側邊欄「常用素材庫」摺疊區可一鍵加入。logo 也可以直接拖進拖放區再把標籤切成「logo」。

## 使用流程

1. 點入稿表任一檔期欄位（B 欄以後），側邊欄自動讀「品類」「廣告名稱」「文案」「預算分配」。
2. **文案**：選調性，按「生成 3 版文案」，點一版當選定。
3. **圖**：把參考圖、自己的舊稿（標籤切「原稿」）、產品去背圖拖進來。對話框留白，自己用中文講，或按「依文案產生風格提示 →」讓模型依選定文案寫一段風格描述。排法預設「自動輪替」，每次「重來」會換一種（價格牌 → 置中疊排 → 左字右圖 → 上字下圖），底部資訊帶只有自己選才會出現；強調色預設不用黃。選「完整稿」或「只畫背景」、品質、比例，按「產圖」。不滿意就繼續打字，例如「膠囊再大一點、背景再亮」。
4. 成品出現後，「只畫背景」模式預設疊上真實產品圖，可在圖上拖曳；完整稿模式文字與產品都由模型畫進圖裡。「圖上文字」摺疊區的主標、優惠、價格、檔期、註記是給模型畫的內容。
5. 「下載」或「存雲端」，「需求單」會把檔期、商品、選定文案、生圖對話、備註整理成文字並複製到剪貼簿。

## 給設計師調的地方（都在 Code.gs 開頭）

- `HOUSE_TEMPLATE`：momo 稿的固定版型規範（品牌區、主標、價格牌、字體規格、momo 元素一律粉紅）。
- `TEXT_LAYOUTS` / `AUTO_LAYOUT_ORDER` / `ACCENTS`：文字排法選項、自動輪替順序、強調色組合。
- `BRAND_PROFILES` / `detectBrand`：四個品牌的關鍵字、事實與自動判斷規則。
- `LAYOUTS`：「只畫背景」模式的留白指令，以及成品預覽疊圖的預設位置。
- `buildChatInstruction`：生圖對話第一輪的開場指令（品牌、模式、產品圖與參考圖的用法）。
- `CHAT_IMAGE_MODELS`（生圖對話，預設 gpt-5.6-terra）與 `TEXT_MODEL_CANDIDATES`（文案，預設 gpt-5.6-luna）；想更強把 gpt-5.6-sol 放第一個。不支援的參數會自動拿掉重送。
- `IMAGE_QUALITY`：預設品質，側邊欄可逐次改。

## 給業務調的地方

- `BRAND`：受眾、語氣、禁用字（文案用）；`BRAND_PROFILES`：各品牌事實（生圖用）。
- `TONE_GUIDE` / `TONE_EXAMPLES` / `BAD_EXAMPLES`：各調性寫法、範例、反例。範例越多越像。
- 「產品資料」分頁：不用改程式碼，直接在試算表填。

## 已知限制

- **完整稿模式的產品包裝小字仍可能出錯。** 「忠實重現、看不清寧可留白」的指令能改善，但這是模型重畫，不是貼圖。出稿前放大檢查包裝文字；要百分之百正確就用「只畫背景」模式，再疊真實 PNG。
- **ChatGPT 訂閱（Go／Plus）不能連到 API。** 兩者分開計費。這個工具用的是同一套生圖機制，但走 API 金鑰按量付費。
- **對話有時效。** `previous_response_id` 過期會提示重新開始對話。
- 貼網址有時會被對方網站擋（回 403）。改成對圖片按右鍵另存，再拖進側邊欄。
- 側邊欄會先把參考圖縮到 1536px、產品圖縮到 1024px 再上傳，避免傳輸過慢。
- 生圖組織驗證：若生圖回 403 或提到 verification，到 platform.openai.com → Settings → Organization → General 完成 Organization Verification。
- API Key 存在 Apps Script 屬性，所有對這份試算表有編輯權的人都能開 Apps Script 讀到。外部廠商只給檢視權限，或另開一把專用金鑰方便撤銷。
- 這份試算表是「的副本」：複製試算表時腳本會一起複製，但授權要重做、觸發條件不會複製。
