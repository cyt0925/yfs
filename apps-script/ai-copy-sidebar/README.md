# 橘子工坊｜AI 文案 x 生圖 x 草稿合成 側邊欄

Google Sheets 的 Apps Script 側邊欄，掛在 CPAS 廣告素材入稿表上用。
不會改動試算表任何內容，所有產出只顯示在側邊欄，要不要用由人決定。

三個步驟對應三層問題：

| 步驟 | 做什麼 | 解決的問題 |
|---|---|---|
| 1 文案 | 品牌語氣＋產品資料＋時事先提切角，再寫 3 版三行文案 | 文案乾、有大陸用語、時事硬湊 |
| 2 生圖底圖 | 主色調／視覺風格／版面由程式填空組 Prompt，可勾選雲端硬碟的去背產品圖與參考成品一起送給 gpt-image-1 | Prompt 說藍色卻出橘色、畫面沒有產品 |
| 3 合成草稿 | 側邊欄用 canvas 把底圖、真實去背 PNG、中文主標副標、角標、logo 疊起來 | AI 寫不出正確的「滿$1099折$150」與正確包裝 |

## 安裝

1. 開入稿表 → **擴充功能 → Apps Script**。
2. 把 `Code.gs` 全部內容貼進編輯器的 `Code.gs`（取代原本內容）。
3. 左側「檔案」旁按 ＋ → HTML，命名 `Sidebar`（不要打副檔名），貼上 `Sidebar.html` 全部內容。
4. Ctrl+S 存檔，回試算表 **重新整理整個分頁**，選單列會出現「AI 文案工具」。
5. 「AI 文案工具 → 設定 OpenAI API Key」貼上金鑰。第一次會要求授權：選帳號 → 進階 → 前往專案 → 允許。
6. 「AI 文案工具 → 建立雲端硬碟素材資料夾」，會在你的雲端硬碟根目錄建四個資料夾：

   | 資料夾 | 放什麼 |
   |---|---|
   | 橘子工坊產品去背圖 | 去背 PNG，一個檔一個產品，檔名就是側邊欄顯示名稱 |
   | 橘子工坊參考成品 | 設計師做過的成品圖，給 AI 借氛圍用 |
   | 橘子工坊品牌素材 | `logo.png`（檔名含 logo 即可） |
   | 橘子工坊生圖 | 產出會存這裡 |

7. （選用）「AI 文案工具 → 建立產品資料分頁」，會新增「產品資料」分頁並填入範本。A 欄關鍵字只要包含在入稿表「品類」文字裡，側邊欄就自動帶入該列賣點。
8. 「AI 文案工具 → 開啟 AI 文案側邊欄」。

## 使用流程

1. 點入稿表任一檔期欄位（B 欄以後），側邊欄自動讀「品類」「廣告名稱」「文案」「預算分配」。
2. **步驟 1**：選調性。若有時事，先在「本週時事／梗料」寫清楚事件與它跟洗衣清潔的關聯，按「先請 AI 提 5 個切角」挑一個，再按「生成 3 版文案」。沒有時事就直接生成。
3. **步驟 2**：選主色調（「藍色夏日」會明確要求橘色不能當主色）、視覺風格、版面、比例。勾選要出現的去背產品圖，可再勾一張參考成品。Prompt 可直接改。按「生成底圖」。
4. **步驟 3**：主標／副標／角標會從「文案」列自動抓（例如「滿1099折150」），可改。調字色、字級、產品大小，按「合成草稿」，下載或存雲端硬碟。

## 給設計師調的地方（都在 Code.gs 開頭）

- `PALETTES`：每個主色調的英文描述、合成時的字色與角標色。
- `VISUAL_STYLES`：每種視覺風格的英文描述。
- `LAYOUTS`：版面的英文描述，以及 canvas 合成用的標題區／產品區比例（0～1）。
- `IMAGE_HARD_RULES`：所有生圖共用的硬規則。
- `IMAGE_QUALITY`：`low` / `medium` / `high`，high 一張成本約 3～4 倍。

## 給業務調的地方

- `BRAND`：受眾、語氣、品牌事實、禁用字。
- `TONE_GUIDE` / `TONE_EXAMPLES` / `BAD_EXAMPLES`：各調性寫法、範例、反例。範例越多越像。
- 「產品資料」分頁：不用改程式碼，直接在試算表填。

## 已知限制

- gpt-image-1 帶產品圖進去（edits 模式）時，產品形狀與配色會對，但標籤上的小字會變形。第三步預設在 edits 模式下不再疊產品，若要精準包裝就改勾「疊上勾選的去背產品圖」並在第二步不勾產品，讓 AI 只畫背景。
- 生圖組織驗證：若生圖回 403 或提到 verification，到 platform.openai.com → Settings → Organization → General 完成 Organization Verification。
- API Key 存在 Apps Script 屬性，所有對這份試算表有編輯權的人都能開 Apps Script 讀到。外部廠商只給檢視權限，或另開一把專用金鑰方便撤銷。
- 這份試算表是「的副本」：複製試算表時腳本會一起複製，但授權要重做、觸發條件不會複製。
