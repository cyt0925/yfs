# 橘子工坊｜AI 文案 x 生圖 x 草稿合成 側邊欄

Google Sheets 的 Apps Script 側邊欄，掛在 CPAS 廣告素材入稿表上用。
不會改動試算表任何內容，所有產出只顯示在側邊欄，要不要用由人決定。

貼近實際流程：**先在網路上找到「想要這種感覺」的圖 → 拖進側邊欄 → AI 分析配色風格 → 用同樣風格生成並換上自家產品 → 疊正確標題 → 一鍵產出給設計師的需求單**。
所有操作都在側邊欄內完成，圖片直接拖放、選檔、Ctrl+V 貼上或貼網址，不需要先整理雲端硬碟。

側邊欄只有兩個區塊：

| 區塊 | 做什麼 |
|---|---|
| 文案 | 填商品、選調性，有時事就先「提 5 個切角」，再「生成 3 版文案」，點一版當選定 |
| 圖 | 一個拖放區丟參考圖與產品去背圖（有透明邊的自動當產品，可點標籤切換）；一個對話框用中文講要什麼，按「產圖」；繼續打字就是改上一張。成品直接顯示在下方，標題、產品、logo 可在圖上拖曳；「下載」「存雲端」「需求單」都在同一處 |

生圖走 OpenAI Responses API 的 `image_generation` 工具，也就是 ChatGPT 生圖背後同一套機制：GPT 先看懂中文、參考圖、產品圖，自己寫指令產圖，之後用 `previous_response_id` 延續修改；影像模型不指定版本，交給 OpenAI 用最新的（目前是 gpt-image-2）。

## 安裝

1. 開入稿表 → **擴充功能 → Apps Script**。
2. 把 `Code.gs` 全部內容貼進編輯器的 `Code.gs`（取代原本內容）。
3. 左側「檔案」旁按 ＋ → HTML，命名 `Sidebar`（不要打副檔名），貼上 `Sidebar.html` 全部內容。
4. Ctrl+S 存檔，回試算表 **重新整理整個分頁**，選單列會出現「AI 文案工具」。
5. 「AI 文案工具 → 設定 OpenAI API Key」貼上金鑰。第一次會要求授權：選帳號 → 進階 → 前往專案 → 允許。
6. 「AI 文案工具 → 開啟 AI 文案側邊欄」，開始用。

選用項目，不做也能用：

- 「建立產品資料分頁」：新增「產品資料」分頁並填入範本，A 欄關鍵字只要包含在「品類」文字裡就自動帶入賣點。
- 「建立雲端硬碟常用素材庫」：在雲端硬碟建四個資料夾，放每次都會用到的產品去背圖、設計師成品與 `logo.png`。側邊欄第一步最下方「從雲端硬碟常用素材庫加入」可一鍵加入。logo 只能從這裡來，沒放就不疊 logo。

## 使用流程

1. 點入稿表任一檔期欄位（B 欄以後），側邊欄自動讀「品類」「廣告名稱」「文案」「預算分配」。
2. **文案**：選調性，按「生成 3 版文案」，點一版當選定。
3. **圖**：把參考圖、產品去背圖拖進來。對話框第一句會依文案自動填好，可改。選「完整稿」或「只畫背景」、品質、比例，按「產圖」。不滿意就繼續打字，例如「膠囊再大一點、背景再亮」。
4. 成品出現後，完整稿模式預設不再疊字疊產品（圖裡已有），只畫背景模式預設都疊；點「疊標題／疊產品／疊 logo」切換，在圖上拖曳位置。「圖上文字、字色、大小」摺疊區可改主標副標角標。
5. 「下載」或「存雲端」，「需求單」會把檔期、商品、選定文案、生圖對話、備註整理成文字並複製到剪貼簿。

## 給設計師調的地方（都在 Code.gs 開頭）

- `PALETTES`：每個主色調的英文描述、合成時的字色與角標色。
- `LAYOUTS`：「只畫背景」模式的留白指令，以及成品預覽疊圖的預設位置。
- `buildChatInstruction`：生圖對話第一輪的開場指令（品牌、模式、產品圖與參考圖的用法）。
- `CHAT_IMAGE_MODELS`：負責看圖寫指令的 GPT 模型清單，依序嘗試。
- `IMAGE_QUALITY`：預設品質，側邊欄可逐次改。

## 給業務調的地方

- `BRAND`：受眾、語氣、品牌事實、禁用字。
- `TONE_GUIDE` / `TONE_EXAMPLES` / `BAD_EXAMPLES`：各調性寫法、範例、反例。範例越多越像。
- 「產品資料」分頁：不用改程式碼，直接在試算表填。

## 已知限制

- **完整稿模式的產品包裝小字仍可能出錯。** 「忠實重現、看不清寧可留白」的指令能改善，但這是模型重畫，不是貼圖。出稿前放大檢查包裝文字；要百分之百正確就用「只畫背景」模式，再疊真實 PNG。
- **ChatGPT 訂閱（Go／Plus）不能連到 API。** 兩者分開計費。這個工具用的是同一套生圖機制，但走 API 金鑰按量付費。
- **對話有時效。** `previous_response_id` 過期會提示重新開始對話。
- 貼網址有時會被對方網站擋（回 403）。改成對圖片按右鍵另存，再拖進側邊欄。
- 側邊欄會先把參考圖縮到 1536px、產品圖縮到 1024px 再上傳，避免傳輸過慢。
- 生圖組織驗證：若生圖回 403 或提到 verification，到 platform.openai.com → Settings → Organization → General 完成 Organization Verification。
- API Key 存在 Apps Script 屬性，所有對這份試算表有編輯權的人都能開 Apps Script 讀到。外部廠商只給檢視權限，或另開一把專用金鑰方便撤銷。
- 這份試算表是「的副本」：複製試算表時腳本會一起複製，但授權要重做、觸發條件不會複製。
