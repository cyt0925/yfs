# 隱私權政策｜AI 文案助手（Google Sheets 側邊欄）

最後更新：2026-09-09

「AI 文案助手」是永豐餘消費品內部使用的 Google Sheets 附加腳本，供行銷人員在廣告素材入稿表旁生成文案與圖片草稿。本頁說明它會碰到哪些資料，以及資料去了哪裡。

## 會讀取的資料

- 你目前在試算表中選取的欄位內容（品類、廣告名稱、文案、預算分配、上檔日期）。
- 你主動拖進側邊欄的圖片，以及你在對話框輸入的文字。
- 你選擇「存雲端」時，會在你的 Google 雲端硬碟建立資料夾並寫入產出的圖片。
- 你按「更新程式到最新版」時，會讀取並改寫這個 Apps Script 專案本身的程式碼檔案。

腳本不會修改試算表的任何儲存格，也不會讀取目前選取欄位以外的內容。

## 資料會傳到哪裡

- 上述文字與圖片會傳送到 OpenAI API（api.openai.com）以生成文案與圖片。其使用受 [OpenAI API 資料使用政策](https://openai.com/policies/api-data-usage-policies) 規範；API 資料預設不用於訓練模型。
- 更新程式時，會從 GitHub（github.com / raw.githubusercontent.com）下載本專案的原始碼，並透過 Google Apps Script API 寫回專案。
- 除此之外，不會把資料傳給任何第三方。

## 儲存

- OpenAI API 金鑰存在 Apps Script 的指令碼屬性中，只有對這份試算表有編輯權的人能透過 Apps Script 編輯器讀到。
- 側邊欄不會在瀏覽器以外保留任何生成內容；關閉側邊欄即清除。
- 產出圖片只有在你按「存雲端」時才會寫入你的雲端硬碟。

## 要求的 Google 權限

| 權限 | 用途 |
|---|---|
| 檢視目前試算表 | 讀取選取欄位的文案資料 |
| 顯示側邊欄與對話框 | 側邊欄介面 |
| 連線至外部服務 | 呼叫 OpenAI API、下載更新 |
| 存取雲端硬碟 | 建立素材資料夾、存圖、讀取常用素材 |
| 修改 Apps Script 專案 | 一鍵更新程式碼 |
