# 蝦皮特選寄倉訂單系統：設計筆記

網址 `/shopee`，程式在 `shopee/`，資料表 `shp_` 開頭（跟酷澎的訂單不共用）。
依據：Jerry 2026-10-07 給的「蝦皮特選寄倉訂單系統需求初稿」（Word，20 頁）＋同一天給的範例檔
（PG 竹運進貨、PG 直出、竹運出、紙潔、瑪氏、EC 即時庫存、竹運庫存效期表、價格本）。真檔只放在工作區，不進 repo；
測試檔照表頭用程式造（`test_shopee.py`）。

進度用 Jerry 的 Word 原檔複本追蹤，每做完一項在上面劃掉再傳給 Jerry。

## 一、現在做到哪

第一段（2026-10-07）：上傳採購單／入庫單、重傳覆蓋＋版本保留＋差異警示與確認、人工選履約方式、訂單總覽、改履約方式、上傳紀錄與原始檔下載。
首頁「各通路系統」的蝦皮特選卡片接上真的數字（今日新進、待出貨；本月出貨要等第三段有出貨量），今日事項多一項「蝦皮特選重傳後有差異」。

第二段（2026-10-08，寶僑、紙潔）：價格本上傳（轉換率）、竹運採購進貨／直送訂單勾選產出 EIP 採購單＋採購下採明細（zip）、
除不盡轉換率要人改數量＋寫原因、採購單產出頁回填 EIP 單號（回填後鎖住不能重產）。程式在 `shopee/purchase.py`。
畫面上方的步驟改成頁籤：訂單匯入與總覽／竹運採購進貨／直送訂單／採購單產出（竹運出貨、缺貨維護與通知還沒做，淡色）。

瑪氏直送（2026-10-12）：直送訂單頁可以勾瑪氏的單產 EIP 採購單；回填 EIP 採購單號後，在採購單產出頁下載瑪氏制式採購單（單份或打包）；
蝦皮倉資料（瑪氏採購單表頭用）在採購單產出頁可以改。EIP 在 `shopee/purchase.py`，瑪氏採購單和倉資料在 `shopee/mars_po.py`。

竹運出貨（2026-10-12）：竹運出貨頁籤上傳 EC 即時庫存、竹運庫存效期表、竹運商品主檔，系統判斷每品可出貨量、選效期批次，
人可以改出貨量、合併效期；勾選訂單產出訂單系統拋單檔＋下修刪單清單。程式在 `shopee/ship.py`。

缺貨維護與通知（2026-10-12，第一段）：缺貨維護與通知頁籤，寶僑兩次、紙潔一次人工填缺貨；竹運出貨的缺貨產拋單檔後自動帶入；
勾選訂單產生蝦皮通知（照 Alice 的 LINE 機器人格式，一張 PR 一種處理一則，逐則複製）＋Excel 明細；通知過的那次鎖住。程式在 `shopee/short.py`。

瑪氏缺貨核對（2026-10-13）：缺貨維護與通知頁籤最上面上傳勇信配送明細表 PDF，系統用收貨單號對回已回填的瑪氏 EIP，逐品比箱數，
確認後寫成缺貨紀錄（來源「勇信核對」），再跟寶僑、紙潔一樣勾選訂單產 LINE 通知。程式在 `shopee/yx.py`，讀檔直接用酷澎瑪氏的 `mars.shortage.parse_yx_pdf`。

## 三、檔案格式（讀範例檔整理的）

- **採購單 PurchaseOrder_…xlsx**：一個檔可以有好幾張 PR／PO。欄：PR ID、PO ID（還沒成 PO 時空白）、Warehouse、Expected Delivery Time（到貨日）、
